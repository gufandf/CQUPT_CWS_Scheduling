使用指南

      
    

    

      

        
1. 导入学号：点顶部「文件」菜单 → 导入学号…，在弹出的窗口里粘贴 10 位学号（每行一个）后点「导入」。
          导入 / 导出数据、导入 / 导出值班模板、编辑值班模板、重置排班、导出值班表 / 空课表，也都在这个「文件」菜单里。

        
2. 开始排班：自动获取课表并智能分配值班，无论是否限制班次，都会尽量让每人的班次数相近。
          要不要限制每人每周班次数，由左侧「限制每人每周班次」开关决定：
          不勾选＝谁空谁上、不限班次；勾选＝每人每周不超过右侧填写的数值（单周、双周各自单独计数）。
          课表冲突与班次人数上限始终都会遵守。

        
3. 查看/调整：右侧表格始终显示当前值班模板的时段（未排班时人数显示为 0/N），
          可拖拽学生标签到其他班次调整，也可以直接把左侧的同学拖进格子手动排班。

        
4. 连续排班：左侧的「连续排班」开关决定同一人的班次怎么摆放。
          勾选＝尽量把班次连成片（同一天首尾相接的班次尽量给同一个人，相邻几天也尽量连着排）；
          不勾选（默认）＝反过来尽量分散，避免连班、也避免连着几天都排同一个人。
          这项只是「尽量」的偏好：算法只做不改变任何人班次数的等价交换，因此在满足它的同时
          不会破坏上面两种模式的均衡性（开关状态会记在浏览器里）。

        
5. 排班锁定：点学生标签上的锁图标可锁住
          「该同学 + 该班次」这个位置——锁定后无论怎么重新排班都不会改变它。
          锁定的标签显示为琥珀色、不能拖动也不能移除（先解锁再操作）；
          该同学在其它班次仍可被正常安排。锁定会随「导出/导入数据」一起保存。

        
6. 课表管理：点击学生姓名查看课表，可忽略特定课程后重新排班。

        
7. 值班模板：顶部「文件」菜单 → 编辑值班模板…可自定义每个班次的值班时间、值班人数、单双周，
          自由添加/删除/排序班次，并单独设置与该时段冲突的课程节次。

          排班日分组支持两种模式：「工作日 / 周末」为预设两组；「一周 7 天自由组合」可自定义分组数量、
          名称与每组包含的星期（例如周一周二一组、周三到周日一组），每组各自一套班次。
          模板会自动保存在浏览器中，也可导出为文件分享给他人（顶部「文件」菜单 → 导出/导入值班模板）。

        
8. 导出：支持导出值班表/空课表为 Excel，导出/导入排班数据为 JSON（含值班模板与锁定），
          全部集中在顶部「文件」菜单。

        
        

          提示：含"实训""实习""课程设计"等关键词的课程会被自动忽略。

          点击课表弹窗中的「刷新」可单独更新某同学的课表。

          切换主题请用顶部「个性化」菜单（深夜模式 / 日间模式 / 跟随系统）。

          软件版本与开发者信息见顶部「关于」菜单 → 软件信息。
